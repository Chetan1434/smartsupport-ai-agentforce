# Knowledge sample articles (manual creation)

Salesforce Knowledge cannot be created from a metadata file in this project, so these five fictional articles are provided as text.

1. Setup > Knowledge Settings > enable Lightning Knowledge (one-way, irreversible per org; use a sandbox or Developer Edition) and enable it for your user (User record > "Knowledge User").
2. App Launcher > Knowledge > New. For each `NN-*.md` file copy Title, URL Name, Summary and Body into the article (map "Body" to the rich text field of your article record type; add one if none exists).
3. Publish each article (channel: Internal App at minimum).
4. Verify with the Knowledge Assistant on the SmartSupport Home page: "How do I reset my password?" should find article 1; "refund policy for enterprise" should answer **insufficient evidence** and offer a human handoff.

All content is fictional.
